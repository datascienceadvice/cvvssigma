## Как получены файлы

Ответы API получены инструментом веб-доступа, который не пишет файлы напрямую: полный
ответ сохраняется во временный файл обрезанным на ~100 КБ. Оттуда тела были перенесены
в этот каталог, при этом:

- отрезана служебная преамбула, добавляемая инструментом;
- сохранено только тело ответа, начиная с первого `{` или `[`;
- в `_provenance.csv` записан исходный URL каждого файла.

Сами тела ответов (`*.json`, `topup_meta.csv`) в репозиторий не публикуются: они содержат
контент базы EFLM, распространение которого лицензией не допускается (см. `.gitignore`
и раздел о лицензии в `../../README.md`).

Проверка: длина всех тел равна 100 078 символов (различия в размерах на диске —
следствие многобайтовой кодировки UTF-8 в символах `·`, `β`, кириллице).

## Почему не удалось скачать скриптом

Сеть недоступна для любых процессов: `curl` возвращает `http=000` для
`example.com`, `cran.r-project.org` и `biologicalvariation.eu`, в том числе в режиме
`danger-full-access`. Подробнее — в `../../README.md`, раздел 1.

## Воспроизведение

Файлы в этом каталоге — рабочая копия. Повторная выгрузка возможна только через
`web_fetch` вручную и даст другие значения, если база обновилась: записи содержат
поле `updated_at`, самые свежие — сентябрь 2026 г.
