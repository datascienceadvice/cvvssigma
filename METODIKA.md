# Методика расчёта

Документ описывает формулы, допущения и способ оценки, использованные в конвейере
`R/run-all.R`. Числовые результаты воспроизводятся одной командой:

```powershell
& 'D:\R\R-4.3.1\bin\Rscript.exe' --vanilla R\run-all.R
```

## 1. Аналитические цели по биологической вариации

Источник формул — открытые публикации:

1. Fraser CG, Petersen PH. Desirable standards for laboratory tests if they are to
   fulfill medical needs. *Clin Chem.* 1993;39(7):1447–1453.
2. Ricós C, Alvarez V, Cava F, et al. Current databases on biological variation: pros,
   cons and progress. *Scand J Clin Lab Invest.* 1999;59(7):491–500.
3. Aarsand AK, Fernandez-Calle P, Webster C, et al. The EFLM Biological Variation Database.
   https://biologicalvariation.eu/ (дата доступа 25.09.2026).

Готовая открытая реализация, использованная для сверки формул — пакет `valytics` (CRAN),
функция `ate_from_bv()`.

**Формулы.** Для каждого аналита и уровня строгости:

```
CV_A  = m_imp  × CV_I
Bias  = m_bias × sqrt(CV_I² + CV_G²)
TEa   = k × CV_A + Bias,        k = 1.65
```

где `CV_I` — внутрииндивидуальная, `CV_G` — межиндивидуальная биологическая вариация, %;
`CV_A` — допустимая аналитическая неточность; `Bias` — допустимое смещение;
`TEa` — допустимая суммарная ошибка; `k` — множитель допустимой неточности (1.65 для ~95 %).

**Множители по уровням:**

| Уровень | `m_imp` | `m_bias` |
|---|---|---|
| optimal | 0.25 | 0.125 |
| desirable | 0.50 | 0.250 |
| minimum | 0.75 | 0.375 |

Отношение `m_bias / m_imp` одинаково для всех уровней и равно 0.5 — это используется
при интерпретации результатов.

**Чувствительность к множителю допустимой неточности.** `CV_A` и `Bias` от `k` не зависят, поэтому
пересчёт при другом `k` сводится к изменению `TEa`. Расчёт выполняется для набора
`K_SET = {1.0, 1.65, 1.96, 2.0, 2.58}` (от ≈ 84 % до ≈ 99.5 % одностороннего охвата);
результат — `out/k_sensitivity.csv`, сводка — таблица S3 в `out/supplementary_tables.md`.
Основной расчёт во всех остальных выходных файлах — при `k = 1.65`; совпадение ключевых
чисел с основным расчётом проверяется в `R/02-sigma.R` (контроль регрессии).

## 2. Допущение об общей TEa

Сопоставление двух рамок имеет смысл только при одной и той же величине `TEa`:
сигма-метрика определена относительно конкретного значения допустимой суммарной ошибки.

В расчёте принято, что сигма-метрика оценивается относительно `TEa`, выведенной из
биологической вариации, то есть той же величины, которая задаёт цели. Это наиболее
строгая постановка. Если лаборатория использует `TEa` из другого источника (CLIA,
RiliBÄK, рекомендации профессиональных сообществ, данные внешней оценки качества),
сопоставление относится к другой задаче: при более широкой `TEa` пороговые значения
сигмы достигаются, а связывающим ограничением становятся цели по биологической
вариации (Weykamp C. et al. *Clin Chem.* 2015;61(5):752–759;
Ilardo C. et al. *Ann Lab Med.* 2026, doi:10.3343/alm.2026.0092).

## 3. Сигма-метрика

```
sigma = (TEa − |Bias_набл|) / CV_набл
```

Категории: ≥ 6 world class, ≥ 5 excellent, ≥ 4 good, ≥ 3 marginal, ≥ 2 poor, < 2 unacceptable.
Источник: Westgard JO, Westgard SA. *Am J Clin Pathol.* 2006;125(3):343–354.

Отмечаемые в литературе ограничения сигма-уравнения (линейное включение смещения;
неоднозначность связи сигмы с частотой дефектов) на результаты настоящего расчёта не
влияют, поскольку сопоставление ведётся в терминах требований к неточности при заданной
`TEa`, а не в терминах частот дефектов:
Oosterhuis WP, Coskun A. *Biochem Med (Zagreb).* 2018;28(2):020503;
Coskun A. et al. *Biochem Med (Zagreb).* 2019;29(1):010902.

## 4. Требование к неточности метода (обратная задача)

Поскольку база EFLM содержит только `CV_I` и `CV_G`, наблюдаемая неточность метода
неизвестна. Вместо подстановки произвольного значения решается обратная задача:

```
CV_требуемая(sigma_цель) = (TEa − |Bias_набл|) / sigma_цель
```

Рассматриваются два сценария по смещению:

- **bias = 0** — идеализированный случай, даёт минимально необходимое требование к неточности;
- **bias = допуск** — метод работает на границе допуска по смещению.

Целевые значения сигмы — 4, 5 и 6.

## 5. Аналитическое сопоставление двух рамок

Ключевая величина — отношение требования сигма-метрики к допустимой неточности по
биологической вариации:

```
ratio = CV_требуемая / CV_A
```

`ratio < 1` означает, что достижение заданной сигмы требует неточности **строже** той,
что считается допустимой по биологической вариации.

**Сценарий bias = допуск.** `TEa − Bias = k × CV_A`, откуда

```
CV_требуемая = k × CV_A / sigma_цель
ratio        = k / sigma_цель
```

Отношение не содержит ни свойств аналита, ни множителей уровня строгости: при смещении
на границе допуска оно определяется только целевой сигмой. Условие `ratio < 1` выполнено
при `sigma_цель > k`, то есть при любой сигме выше 1.65. Численно: 0.4125 (4σ),
0.3300 (5σ), 0.2750 (6σ).

**Сценарий bias = 0.** Обозначив `R = sqrt(1 + (CV_G/CV_I)²)`,

```
ratio = (k + 0.5 × R) / sigma_цель
```

Зависимость от аналита сохраняется только через отношение `CV_G / CV_I`; множитель уровня
сокращается, поскольку `Bias / CV_A = 0.5 × R` одинаково на всех уровнях. Аналит перестаёт
быть затронутым при

```
CV_G / CV_I > sqrt(4 × (sigma_цель − k)² − 1),
```

то есть при 4.59 (4σ), 6.62 (5σ) и 8.64 (6σ).

**Что именно инвариантно.** Инвариантность к уровню строгости относится к отношению
`CV_требуемая / CV_A`. Отношение к внутрииндивидуальной вариации
`CV_требуемая / CV_I = k × m_imp / sigma_цель` от уровня **зависит** (0.0688 / 0.1375 /
0.2063 при 6σ для optimal / desirable / minimum), как и абсолютная величина требуемой
неточности. Утверждение «аналитические свойства показателя не входят» верно только для
отношения, но не для абсолютной величины.

**Контроль.** Замкнутые выражения проверяются в `R/02-sigma.R` по всей панели; максимальное
расхождение с теоретическими значениями не превышает 1e−14 (ошибка округления чисел
с плавающей запятой). Числа для двух контрольных точек (натрий, С-реактивный белок)
сохраняются в `out/worked_example.csv`. Исчерпывающие перечни аналитов, не затронутых
расхождением при нулевом смещении, формируются в `out/table_s2_threshold_analytes.csv`
(публикуются только производные величины — отношения `CV_G/CV_I` и `CV_треб/CV_A`).

## 6. Операционные характеристики правил контроля

Правила Вестгарда: 1-3s, 2-2s, R4s, 4-1s, 10x.
Источник: Westgard JO, Barry PL, Hunt MR, Groth T. *Clin Chem.* 1981;27(3):493–501.

Обозначения: `z` — результат контроля в единицах стандартного отклонения метода;
сдвиг задаётся в тех же единицах. Правила 2-2s и 4-1s применяются к последовательности
измерений с переходом через границу серии, правило R4s — только внутри серии.

**Pfr (стационарная вероятность ложного сигнала на серию).** Оценивается как доля серий,
в которых схема срабатывает, на цепочках, достигших стационарного режима: 100 000
независимых цепочек по 50 серий, первые 20 серий исключены как прогрев (необходимо для
правил, использующих историю). Доверительный интервал — по разбросу долей между цепочками
(t-распределение), что учитывает корреляцию серий внутри цепочки.

Оцениватель не смещён и не ограничен сверху. Прежний вариант — доля репликатов, в которых
срабатывание произошло хотя бы раз за окно фиксированной длины, — систематически смещён
вниз примерно в `[1 − (1 − p)^K] / (K × p)` раз (при `p = 0.0027` и `K = 50` это около
−6.4 %) и при больших `p` упирается в потолок `1/K`. Смещение демонстрируется численно:
оба оценивателя считаются на одних и тех же цепочках, результат — `out/estimator_comparison.csv`
и таблица S4 (отношение составляет ≈ 0.95 для 1-3s при N = 1 и ≈ 0.42 для полного набора
правил при четырёх измерениях).

**ARL (средняя длина серии до сигнала).** Определяется напрямую как среднее число серий от
начала контроля без предшествующей истории до первого сигнала (zero-state ARL — стандартное
для статистического контроля процесса определение): 10 000 цепочек, длина `L` выбирается как
`min(max(300, 12 / Pfr), 6000)` так, чтобы доля цензурированных наблюдений была порядка 1e-5;
доверительный интервал — по разбросу времён между цепочками. Оцениватель устойчив к
цензурированию: цепочки, не давшие сигнала за `L` серий, не отбрасываются, а получают
подстановочное значение `L + 1/Pfr` (ожидаемое остаточное время). Отбрасывание таких цепочек
систематически занижает ARL, поскольку отбрасываются самые длинные наблюдения: прежняя версия
оценивателя давала 182.4 против точного 185.4 для 1-3s при N = 2 и 365.4 против 370.4 при
N = 1, и именно этим объяснялось расхождение, выглядевшее как статистическая погрешность.
Величина `1 / Pfr` совпадает с zero-state `ARL` только для правил без памяти (1-3s); для
правил с памятью (2-2s, 4-1s, 10x) распределение времени до сигнала не является
геометрическим, поэтому `1 / Pfr` сопоставляется с ARL заполненного буфера, а остаток
различия отражает память правил. Численно расхождение не превышает 3.8 %: 369.6 против 370.5
для 1-3s при N = 1 и 81.3 против 78.3 для multi-rule при N = 2 (там же ARL заполненного
буфера равен 81.2).

Дополнительно оценивается вариант с заполненным буфером: среди цепочек, не давших сигнала
за первые `B_WARM = 20` серий, берётся остаточное время до сигнала (счёт начинается заново,
поэтому величина сопоставима с zero-state ARL); цензурированные цепочки получают подстановку
`(L − B_WARM) + 1/Pfr`. Расхождение двух определений не превышает 1.7 % для всех схем
(например, 368.6 против 369.6 для 1-3s при N = 1 и 24.9 против 25.3 для полного набора при
N = 4), то есть выбор начала наблюдения на результат практически не влияет; полная сводка —
`out/table_s6_arl_start.csv` и таблица S6.

**Ped (вероятность сигнала).** Цепочка начинается в контрольном состоянии (20 серий), затем
вводится постоянный сдвиг и фиксируется, сработала ли схема в пределах 100 последующих серий;
величина включает ложные сигналы. 20 000 цепочек на клетку, интервалы — по методу Уилсона.
Величины сдвига: 0.5; 1; 1.5; 2 и 3 SD метода. Поскольку для правил с памятью результат
зависит от накопленной до сдвига истории, длина контрольного состояния указана в основном
тексте, а не только в примечании к таблице.

**Точные значения для 1-3s.** Для одного измерения при сдвиге `s`
`p₁(s) = Φ(s − 3) + Φ(−3 − s)`; для `N` измерений в серии `p(s) = 1 − (1 − p₁(s))^N`;
`ARL = 1/p(s)`, `Ped = 1 − (1 − p(s))^K`. Значения: Pfr = 0.002700 (ARL 370.4) при N = 1
и 0.005392 (ARL 185.4) при N = 2. Точные значения лежат внутри 95 % ДИ оценок Монте-Карло
как для Pfr, так и для ARL, а отклонение оценок от точных значений составляет −0.2 и +1.3 %
соответственно, что служит контролем корректности всего моделирования.

## 7. Воспроизводимость

Зерно генератора зафиксировано (`set.seed(20260925)`), параметры моделирования вынесены
в начало `R/03-power.R` (`N_REP_FR`, `RUNS_FR`, `BURN_IN`, `N_REP_DET`, `K_RUNS`, `B_RUNS`,

идентичные `out/qc_false_rejection.csv`, `out/qc_power.csv`, `out/estimator_comparison.csv`,
`out/table_s5_level_strictness.csv`, `out/table_s6_arl_start.csv` и рисунки. Полное время

(в фоновом режиме под нагрузкой наблюдалось до десятков минут при идентичных результатах).

## 8. Чего методика не делает

- Не оценивает фактическую неточность конкретных анализаторов: этих данных в открытых
  источниках нет, и они не заменяются синтетикой.
- Не распространяет доверительные интервалы `CV_I` и `CV_G` на выводы: используются
  медианные оценки базы. Часть оценок опирается на одно-три исследования, поэтому
  индивидуальные требования имеют ограниченную точность; аналитические соотношения
  (отношения требований) от значений `CV_I` и `CV_G` не зависят.
- Не вычисляет ARL правил с памятью через марковскую цепь: используется прямое
  моделирование времени до первого сигнала, что даёт те же величины без построения
  матрицы переходов, но с погрешностью Монте-Карло (около 1 % при 10 000 цепочек).
- Не воспроизводит таблицы CLSI и ISO. Числовые критерии взяты только из открытых
  публикаций; платные стандарты упоминаются как источник процедуры, без воспроизведения.
- Не выбирает окончательную схему контроля за лабораторию: результат — карта
  «аналит → требование к неточности → достижимая сигма → схема контроля», решение
  принимается с учётом клинического контекста.
